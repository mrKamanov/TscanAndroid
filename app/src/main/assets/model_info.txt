Model Information:
- Architecture: MobileNetV2 + Custom Classifier  
- Input Size: 64x64 RGB
- Output: 3 classes (no/yes/fixed)
- Training Data: 1800 images (Medium Dataset)
- Test Accuracy: 99.13% ⭐ (на независимом тесте 10,000 изображений)
- Full Dataset Accuracy: 99.13% (на полном датасете 162,674 изображений)

Usage in Android:

2. Preprocess image: resize to 64x64, normalize
3. Run inference
